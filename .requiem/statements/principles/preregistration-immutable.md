Pre-registration documents are kept byte for byte with the hash taken before the run; later changes are dated amendments, never edits. Every result is labelled registered or exploratory. When a later fix changes a registered measure, both versions are reported and the registered verdict stands. Corrections to earlier published numbers are stated where the number appears, with the reason. Constitution III.
