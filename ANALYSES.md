Each row is one module under `analyses/<family>/`. *Label* is `registered` (run exactly as a pre-registration fixed it) or `exploratory`. *Status* is whether the committed result matches the current inputs (`uv run bomstylo status`). The Requiem record holds the headline numbers; `requiem get <record>` reports `stale: true` when an input has changed.
